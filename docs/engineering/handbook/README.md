# Overview

The Engineering Handbook defines the engineering practices that guide day-to-day software development throughout the KnowledgeFlow project.

It establishes the Engineering Practice Framework by translating engineering governance into consistent engineering practices that promote software quality, collaboration, maintainability, and continuous improvement.

This README serves as the official navigation entry point for all Engineering Handbook documentation.

---

# Mission

The mission of the Engineering Handbook is to provide a shared engineering practice framework that enables engineers to work consistently, collaboratively, and sustainably throughout the software development lifecycle.

The Handbook translates engineering governance into practical engineering activities without redefining governance policies, architectural decisions, or business direction.

---

# Practice Scope

The Engineering Handbook defines **how engineering work is performed**.

The Handbook defines:

- engineering philosophy;
- engineering workflows;
- documentation workflows;
- development practices;
- collaboration practices;
- testing practices;
- security practices;
- performance practices;
- engineering culture.

The Handbook does **not** define:

- system architecture;
- engineering governance policies;
- architecture decisions;
- sprint commitments;
- business strategy;
- product roadmap.

These responsibilities belong to their respective authoritative documents.

---

# Practice Responsibilities

The Engineering Handbook is responsible for:

- establishing engineering best practices;
- guiding day-to-day engineering activities;
- promoting consistent engineering workflows;
- supporting engineering collaboration;
- preserving engineering knowledge;
- encouraging continuous improvement.

---

# Engineering Philosophy

Engineering practices are guided by a shared engineering philosophy that promotes:

- Architecture Before Implementation
- Documentation as Engineering
- Working Software First
- Incremental Delivery
- Continuous Improvement
- Quality by Design
- Collaborative Engineering

The complete Engineering Philosophy is maintained in the authoritative Engineering Handbook Specification.

This README intentionally references that document rather than duplicating its guidance.

| Engineering standards | Architecture decisions |
